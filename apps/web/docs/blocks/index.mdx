## Larger Figma blocks

The plugin also generates three larger Blocks-region systems:

- **Chart** — a curated set of Area, Bar, Line, Pie, Radar, and Radial chart variants.
- **Sidebar** — all 16 shadcn sidebar block layouts in one component set.
- **Dashboard** — a realistic dashboard composition built from live component instances.

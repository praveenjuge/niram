Niram turns a [shadcn/ui](https://ui.shadcn.com) preset into native Figma variables, styles, components, and app blocks. Paste one preset code and generate a complete, reusable design-system surface on a single Figma page.

## One preset, one coherent Figma system

- **Native tokens** — Tailwind colors, spacing, radius, typography, opacity, borders, shadows, and blur become Figma variables and styles.
- **Light and dark together** — the free-tier-friendly theme uses one mode with `dark-*` twin variables.
- **Real component instances** — blocks reuse generated components instead of flattening the design into static artwork.
- **Safe to regenerate** — changing presets updates the same collections, styles, and regions in place.
- **Fully offline** — the plugin does not use network requests, analytics, or third-party services.

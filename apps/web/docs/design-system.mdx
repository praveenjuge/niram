The Design System region translates shadcn and Tailwind conventions into editable, native Figma resources.

## Variables

<CardGroup cols={2}>
  <Card title="Tailwind colors" icon="palette">
    OKLCH color scales are converted to Figma colors. Matching theme values alias the Tailwind variable instead of duplicating a literal.
  </Card>
  <Card title="Primitive tokens" icon="ruler">
    Radius, spacing, typography, opacity, border, shadow, and blur values become reusable variables.
  </Card>
  <Card title="shadcn theme" icon="sun-moon">
    Semantic light tokens and their `dark-*` twins live in a single-mode collection for Figma free-tier compatibility.
  </Card>
  <Card title="Token bindings" icon="link">
    Generated dimensions, fills, effects, and typography bind back to variables wherever Figma supports it.
  </Card>
</CardGroup>

## Styles

Niram creates Tailwind typography text styles plus shadow, inner-shadow, blur, and backdrop-blur effect styles. The selected preset's body and heading fonts are loaded before styles and components are generated.

## Page structure

The shared `Niram` page contains three owned regions in a deterministic order:

1. Design System at the top.
2. Components below the Design System.
3. Blocks to the right of the Components grid.

Each region is tagged and regenerated independently, so running the plugin again does not clear unrelated work from the page.

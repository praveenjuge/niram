Niram generates 56 shadcn-style component sections after the Design System region. They use the generated variables, text styles, and effects, so a preset change updates the system consistently.

## Included surface

- Form controls, inputs, selectors, and validation states.
- Buttons, badges, typography, cards, and navigation.
- Data display, tables, avatars, and icon-backed controls.
- Overlays, menus, dialogs, sheets, popovers, and tooltips.
- A `Chart Tooltip` component set for shadcn chart callout chrome.

## Component-first blocks

Components are built before Blocks because app layouts instance the reusable components. The dashboard remains structurally close to shadcn dashboard patterns, and both the Chart and Sidebar ship as Blocks-region component sets.

:::note
Chart shapes and the 16 full Sidebar layouts belong to [Blocks](/blocks), not the Components region.
:::
